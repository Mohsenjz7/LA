# آموزش جبر خطی — فصل‌های ۵ تا ۹

این نسخه شامل فصل‌های ۵ تا ۹ و تمرین‌های دوم و سوم به همراه پاسخ‌هاست.

## باز کردن سایت

فایل ZIP را از حالت فشرده خارج کنید و یکی از روش‌های زیر را اجرا کنید:

- **Windows:** فایل `start-windows.bat` را اجرا کنید.
- **macOS / Linux:** در ترمینال، در پوشهٔ سایت دستور `sh start-mac-linux.sh` را اجرا کنید.
- **با پایتون:** داخل پوشهٔ سایت دستور `python server.py` (یا `python3 server.py`) را اجرا و نشانی `http://localhost:8000` را باز کنید.

بسیاری از مرورگرها با باز کردن مستقیم `index.html` نیز سایت را نشان می‌دهند؛ راه‌اندازی با سرور محلی برای عملکرد قابل‌اعتمادتر پیشنهاد می‌شود. برای اجرای محلی به اینترنت نیازی نیست؛ MathJax و تصاویر در پوشهٔ سایت هستند.

## محتوای جدید

- `pages/08-01.html` تا `pages/08-06.html`: فضای ضرب داخلی، فرم خطی، فرم دوخطی، ضرب داخلی و نرم.
- `pages/09-01.html` تا `pages/09-06.html`: تعامد، متمم متعامد، الگوریتم گرام–اشمیت و چهار زیرفضای بنیادی.
- `pages/nhw3.html`: هشت سؤال تمرین سوم، جواب تشریحی، عکس اصل صورت سؤال و عکس پاسخ‌نامهٔ رسمی برای هر سؤال.
- `pages/nhw2.html` و `pages/ht2.html`: تمرین‌های قبلی زیر مجموعهٔ **تمرین ۲**.
- `content/08-09-original.md`: منبع آموزشی فصل‌های ۸ و ۹؛ جمله‌های غیرآموزشی و مکالمه‌ای از آن حذف شده‌اند. تعریف‌ها، اثبات‌ها، فرمول‌ها، مثال‌ها و مراحل حل حفظ شده‌اند.
- `content/full-transcript.md`: متن جامع همراه فصل‌های جدید و تمرین‌ها.
- `sources/`: PDFهای اصلی فصل‌های ۸ و ۹ و صورت‌سؤال و پاسخ تمرین سوم، علاوه بر فایل‌های قبلی.
- `assets/slides/` و `assets/official-answers/`: تصاویر منتخب اسلایدهای استاد و سؤال‌ها/پاسخ‌های اصلی تمرین سوم.

## بازتولید صفحات

اگر می‌خواهید سورس وب را تغییر دهید، بسته‌های Python به نام‌های `mistune` و `beautifulsoup4` را نصب و دستور `python build.py` را اجرا کنید. **برای استفادهٔ معمول از سایت این بسته‌ها لازم نیستند.**

## ویرایش متن درسنامه

جمله‌های خطاب به خواننده دربارهٔ پاسخ‌های قبلی، فرایند تولید متن یا توصیف ویرایش‌ها از صفحات و فایل متنی یکپارچه حذف شده‌اند. توضیحات درسی، مثال‌ها، روابط ریاضی و PDFهای اصلی تغییر نکرده‌اند. برای بازتولید خروجی سایت از `python build.py` استفاده می‌شود.
